# Vibra

Minimal social web app prototype using Express.js and EJS.

## Setup

1. Run `npm install`.
2. Start the app with `npm start`.
3. Open `http://localhost:3000`.

## Routes

- `/` — Home
- `/about` — About
- `/contact` — Contact

## Notes

- This is a prototype; add authentication, database integrations, and file uploads as next steps.
